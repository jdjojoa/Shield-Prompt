# Portal Objetivo del Laboratorio

## Sitio Principal Analizado

El laboratorio de ciberseguridad y pruebas de seguridad estará enfocado principalmente en el portal:

Latinoamérica Comparte(https://latinoamericacomparte.com/#hero)

La plataforma está orientada a programas sociales, emprendimiento, productividad y transformación empresarial en Latinoamérica. :contentReference[oaicite:1]{index=1}

---

#  Objetivo de las Pruebas

El objetivo será realizar un entorno controlado de:

- Pentesting Web
- Reconocimiento de infraestructura
- Análisis de vulnerabilidades
- Seguridad en formularios
- Seguridad en APIs
- Evaluación de configuraciones
- Simulación de ataques
- Seguridad para IA y chatbots
- Protección contra Prompt Injection


## 🎯 Objetivo

Recolectar información pública sobre el dominio, infraestructura y tecnologías utilizadas por el portal.


##  Qué se analizará

- Subdominios expuestos
- IPs públicas
- Correos filtrados
- Tecnologías del servidor
- Frameworks utilizados
- Certificados SSL
- Información pública sensible

##  Riesgos encontrados comúnmente

- Exposición de infraestructura
- Fugas de información
- Subdominios inseguros
- Enumeración de servicios



##  Qué se analizará

- Headers HTTP
- Cookies
- Tokens
- Sesiones
- Formularios
- Endpoints
- APIs

##  Pruebas realizadas

- Manipulación de peticiones
- Reenvío de solicitudes
- Modificación de parámetros
- Captura de autenticación

##  Vulnerabilidades posibles

- Session Hijacking
- Exposición de tokens
- Cookies inseguras
- Headers inseguros



#  Resultado Esperado

Construir un laboratorio integral capaz de:

- Detectar vulnerabilidades
- Simular ataques reales
- Analizar riesgos
- Mejorar defensas
- Investigar seguridad en IA
- Crear herramientas defensivas
- Documentar hallazgos técnicos
