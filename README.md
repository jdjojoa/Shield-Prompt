# Shield-Prompt

##  Descripción

Shield-Prompt es una plataforma experimental de seguridad enfocada en la protección de modelos de inteligencia artificial y chatbots contra ataques de Prompt Injection, Jailbreaks y manipulación de contexto.

El proyecto funciona como un laboratorio de AI Security donde se simulan ataques ofensivos y se desarrollan mecanismos defensivos para sistemas basados en LLMs (Large Language Models).

---

#  Objetivos

- Detectar Prompt Injection
- Bloquear Jailbreaks
- Analizar comportamiento malicioso
- Proteger sistemas conversacionales
- Implementar AI Firewall
- Evaluar riesgos en prompts
- Simular ataques IA
- Construir entornos seguros para chatbots

---

#  Inteligencia Artificial Defensiva

Shield-Prompt implementa mecanismos de:

- Clasificación de prompts
- Detección semántica
- Filtrado inteligente
- Protección contextual
- Validación conversacional

---

#  Casos de Uso

- Protección de chatbots
- Seguridad en sistemas IA
- Laboratorios educativos
- Investigación de Prompt Injection
- AI Pentesting
- Simulación de ataques LLM

# Instalación

## Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
